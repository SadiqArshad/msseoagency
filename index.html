Honest note — please read: this page alone cannot send email by itself and cannot verify traffic, authority or backlinks. Live auto-send needs the optional backend (server.js on Render, with SMTP details in env vars — never in chat or in the repo). Until a mailbox is connected through the backend, every mail in the Queue is manual only: copy the draft, send it from your own mailbox, then press Mark Sent. Nothing here is ever marked sent unless the SMTP server accepts it or you confirm you sent it yourself.

  1. Naya client: All Clients tab mein + Naya Client form — naam, niche, rules, sender aur template likho. Client save hote hi har jagah aajayega (Prospects, Templates, Campaign, URL Checker). Purane presets sirf examples hain.
  2. Team & Senders: apni Gmail / Hostinger ID add karo. Warmup on rakho — pehle 15/day.
  3. Prospects: Casino Top 50 pehle se loaded hai (example). Client filter badlo, nayi site add karo ya list paste karo — har client ke apne prospects hote hain.
  4. Templates: client select karo — usi client ka fixed email copy karo (budget, link ya attachment nahi).
  5. Campaign & Queue: client select karo → Campaign banao → Build Queue dabao. Har sender ki lane ek saath chalegi, har lane mein 6–7 minute ka gap. Queue mein usi client ka template lagta hai.
  6. Queue: har mail ka time aane par backend se Send karo, ya khud mailbox se bhej kar Mark Sent dabao. Reply aaye to Mark Replied dabao.
  7. URL Checker: client select karo, site ka URL paste karo — checklist usi client ki rules se banti hai. Ye Pass/Fail nahi banata jab tak Semrush/Ahrefs API key na ho. Settings mein key paste karo.
